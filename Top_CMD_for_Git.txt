---

## 🔹 **Essential Git Basics**

1. `git init` – Initialize a new Git repository
2. `git clone <repo-url>` – Clone an existing repository
3. `git status` – Show current status of working directory
4. `git add <file>` – Stage a specific file
5. `git add .` – Stage all files
6. `git commit -m "message"` – Commit with a message
7. `git diff` – View unstaged changes
8. `git diff --staged` – View staged changes
9. `git log` – View commit history
10. `git show <commit>` – Show details of a specific commit

---

## 🔹 **Branching & Navigation**

11. `git branch` – List branches
12. `git branch <name>` – Create a new branch
13. `git checkout <branch>` – Switch to another branch
14. `git checkout -b <branch>` – Create + switch to a new branch
15. `git switch <branch>` – Alternative to checkout (modern)
16. `git switch -c <branch>` – Create and switch (modern)
17. `git branch -d <branch>` – Delete a local branch
18. `git merge <branch>` – Merge a branch into the current one
19. `git rebase <branch>` – Reapply commits on top of another base
20. `git cherry-pick <commit>` – Apply a specific commit from another branch

---

## 🔹 **Remote Repositories**

21. `git remote -v` – Show remote URLs
22. `git remote add origin <url>` – Link remote repository
23. `git push origin <branch>` – Push branch to remote
24. `git pull origin <branch>` – Pull changes from remote
25. `git fetch` – Download commits, not merge
26. `git push --force` – Force push changes (use with caution)
27. `git push -u origin <branch>` – Set upstream tracking

---

## 🔹 **Undo, Reset & Clean**

28. `git reset <file>` – Unstage a file
29. `git reset --hard` – Discard all changes
30. `git reset --soft HEAD~1` – Undo last commit but keep changes
31. `git revert <commit>` – Undo a commit (safe for public branches)
32. `git commit --amend` – Edit the previous commit
33. `git clean -fd` – Delete untracked files and directories

---

## 🔹 **Stashing & Temporary Save**

34. `git stash` – Stash current changes
35. `git stash list` – List all stashes
36. `git stash pop` – Reapply and remove the last stash
37. `git stash apply` – Reapply the last stash (keep it in list)

---

## 🔹 **Debugging, Tags, and Others**

38. `git tag` – List tags
39. `git tag <name>` – Create a tag
40. `git blame <file>` – Show who changed what in each line
